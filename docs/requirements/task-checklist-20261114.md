## 0. 一句话

两周内做出一版能演示的智能体界面：从自然语言进来，经过 L1–L4 判级、建模、方程确认、去幻觉校验，到（黑盒）求解、结果上大理地图，再到与课题 3 风险评估协商，形成闭环。重点是**建模准确、可视化、跨课题接口**，**不做加速**。

## 1. 为什么要调整方向

*   之前两周的精力放在 905 节点 OTS 加速上：热启动后，96 个窗口有 95 个进了 60 秒。老师的判断是这偏离了方向，“现在完全跟加速没有关系”。

*   老师要的是一条完整的界面流程：自然语言是什么样、有几个条件 → 建模 → 缺什么要追问 → 方程确认 → 校验。核心是**每一次建模的精度**，以及建模能**动态调整**（换优化类型、换目标和约束）。

*   任务书的中期考核（**2027 年 1 月**）也落在建模上，不在速度上：

    *   **指标 4.1（中期）**：模拟系统上万级整数决策变量的方式调整问题，完成从人类语言到数学问题的**自动化建模**，模型可用常用商业求解器求解。

    *   **指标 4.2（中期）**：完成基于商业求解器所生成策略的**质量评估指标计算**。

    *   求解 ≤1 分钟是完成时（2028 年）的指标。中期和完成时都要经第三方专家评审测试方案、由有资质的第三方机构测试。

*   加速成果不扔：老师在群里说“一分钟那个指标，有了先留着”。现有的 IPOPT 热启动链路，作为求解黑盒的后端保留。

## 4. 数据与口径（必须统一）

### 4.1 905 节点断面（`pasExp_20261004_153500_1.txt`）

*   规模：Bus 905、Gen 237、Branch 1000，baseMVA \= 100。

*   单位：功率类是 MW / Mvar / MVA 有名值（PD 合计约 1014 MW，PG 合计约 1693 MW）；VM 是标幺值；**VA 是弧度**（和 MATPOWER 的“度”不同）。

*   编号：母线 B{BUS\_I}（不连续，1–4588）；支路按**行号** L{n}，因为有 67 组并联支路，不能用首末母线当主键；机组按行号 G{n}，61 个母线挂了多台机组。

*   平衡节点是母线 175；电压等级包括 500、220、110、35、10、6 kV。

*   一个文件只是一个断面。做 16 时段演示需要连续断面，现在只能把单断面复制成 16 段，并在界面上标明“单断面演示模式”。

### 4.2 数据质量（界面要如实展示，不做修正）

*   231 个母线 VM 高于 VMAX（VMAX 统一为 1.05），2 个低于 VMIN。

*   101 台机组 PG 不在 \[PMIN, PMAX] 内。

*   5 条支路 RATE\_A \= 0。

*   248 个母线 PD < 0（分布式电源按负负荷处理）。

*   母线 176 上有两台约 ±2000 MW 的等值机组。

*   RENEWABLE 列全为 0，没有新能源机组信息，所以新能源消纳率暂不计算。

*   Gen 段没有发电成本数据，目标函数里的经济性项需要另定口径。

### 4.3 “万级整数决策变量”口径（要和老师、铮昊对齐）

*   1000 条支路里有 **775 条一断就形成孤岛**，只有 **225 条**在网状部分。

*   可开断变量数（16 个时段）：

    *   全部支路都可开断：16000 个

    *   只开断网状部分：约 3600 个

    *   网状部分且 ≥110 kV：约 1712 个

*   加上机组启停（237 台 × 16 时段 ≈ 3800 个），合理口径下才能接近或达到万级。这正好和“机组也得做”对上，建议在建模里加入机组启停变量。

### M2 层级判定（ProOPF L1–L4）

*   [ ] 把 L1–L4 做成**选项**：系统自动判级，用户也可以手动改选。

    *   L1：参数明确，不改结构

    *   L2：参数需推断，不改结构

    *   L3：参数明确，要改结构

    *   L4：参数需推断，要改结构

*   [ ] 解析卡片：列出识别到的对象，并在原文里高亮依据。

*   [ ] 推断链（L2、L4）：事件 → 机理 → 参数，例如“高温 → 热稳裕度下降 → 调低线路容量”。

*   [ ] 缺信息时追问，给选项按钮。

*   [ ] 每一级都准备至少一条可演示的指令。

### M3 动态建模、规格与方程确认（核心页）

*   [ ] **铮昊动态建模**的功能入口：多场景优化规则、建模逻辑、结果验证。

*   [ ] **动态调整优化类型**：OPF、OTS、机组出力调整、机组启停，可切换、可组合。

*   [ ] 结构化规格 M \= {ω, Δπ, s, R}：

    *   ω：基础模型；

    *   Δπ：参数修改表；

    *   s：结构修改，包括约束和目标；

    *   R：求解要求。

*   [ ] **目标函数按任务书的类别**来设，包括经济性、可靠性、新能源消纳等。数据里缺成本和新能源信息，相关项要标明口径。

*   [ ] **机组建模**：机组出力约束、出力调整、启停（可选）。

*   [ ] 规格、公式、代码三栏对照：改动的地方高亮，规格和代码可以互相跳转。

*   [ ] 显示模型规模，包括整数变量数和约束数，对应指标 4.1 的“万级”口径。

*   [ ] 版本管理：每次确认生成一个新版本，记录改动原因。

### M4 去幻觉校验与无解诊断
