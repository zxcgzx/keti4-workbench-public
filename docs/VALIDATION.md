# 运行方式智能调整平台B · V4.0

## 运行与交付

- 启动：双击 `start-workbench.cmd`，浏览器访问 `http://localhost:8014`。
- 完整工程：`deliveries/运行方式智能调整平台B-v4.0.zip`。
- 操作指南：`docs/操作指南.md`；接口格式：`docs/接口接入.md`；功能状态：`docs/功能清单.md`。
- 需求范围：覆盖七步流程、M1–M10、905 节点数据、课题 2 / 3 接口入口和本地离线运行。

## 数据与模型口径

- 统一数据包：`data/905节点计算.zip`；2,543 个文件，压缩包 77,954,719 字节，解压 119,004,319 字节。
- 电网规模：905 母线、237 台机组、1,000 条支路，baseMVA=100。
- 编号：母线 `B{BUS_I}`，支路 `L{原始行号}`，机组 `G{原始行号}`；相角单位 rad。
- 原始输入为单断面，16 时段界面明确标为单断面演示模式，不将复制时序解释为真实预测。
- 原始数据中的越限、出力越界、零额定值和负负荷保留，不自动修正。
- 成本与新能源目标需要导入对应数据；缺少数据时不能确认相关目标。
