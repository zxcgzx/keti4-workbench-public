# 运行方式智能调整平台B · 操作指南

## 1. 开始使用

双击 `start-workbench.cmd`，打开 `http://localhost:8014`。启动窗口需保持开启。默认使用离线演示规则引擎；需要使用本地小模型或外部方法时，配置 `.env` 后在页面选择相应引擎。

首页显示当前断面、七步流程、大理地图与 905 节点电气网架。数据来自统一的 `905节点计算.zip`。原始断面只有一个，16 时段窗口显示“单断面演示模式”。

## 2. 七步流程

| 步骤 | 操作 |
|---|---|
| 指令输入 | 选择断面、模型类型与引擎，输入指令或选择 D1–D10 / 机组场景。 |
| 层级判定 | 查看 L1–L4、对象、原文高亮与条件拆解。信息不足时回答时段、幅度和对象等问题。 |
| 规格与方程 | 编辑参数，切换 AC-OPF / AC-OTS、机组控制与目标组合；查看规格、方程、代码对照并确认版本。 |
| 去幻觉校验 | 检查规格、结构、数据、可执行性、语义回译。冲突条目可直接定位回模型。 |
| 求解黑盒 | 选择演示占位、结果导入或外部求解器。存在错误时不能进入。 |
| 结果与地图 | 查看基态或求解结果、开断矩阵、机组曲线、电压与线路状态、前后对比。 |
| 风险与协商 | 查看负载率、电压偏移和 N−1 筛查，选择风险建议生成新版本草稿。 |

模型确认后可直接选择“先协商风险”，不必先进入求解器。新草稿需要填写建议幅度并重新确认；旧版本保留在版本栏中。

## 3. 动态机组建模

“模型规格 → 切换模型与目标”提供三种机组控制方式：

- **出力调整**：有功、无功受上下限约束，可增加目标出力与爬坡限制。
- **固定机组有功**：固定到当前时段出力或用户明确设置的值；原始出力与限值冲突会在无解诊断中指出。
- **机组启停**：生成开机状态、启动、停机变量，包含状态转移、最小开停机时间、初始已持续时段及检修状态约束。

例如：

```text
采用AC-OTS，加入机组启停，最小开机4时段，最小停机4时段，初始已持续4时段，以网损最小为目标。
```

默认网状支路的 16 时段组合包含：线路状态 3600、机组状态 3792、启动与停机事件 7584 个二进制变量，合计 14976。页面分别列出三种数量。

机组启停只决定规划窗口中的模型变量。设备操作回写和实际执行通过课题 2 接口对接，不在页面上直接操作电网设备。

## 4. 目标函数

目标按经济性、可靠性、新能源消纳分类，可组合并修改权重。成本和新能源目标需先导入数据：

| 数据 | CSV 列 | 要求 |
|---|---|---|
| 发电成本 | generator,c2,c1,c0 | 每台机组一行；成本为 c2·P²+c1·P+c0·u，二次项非负。 |
| 新能源可用出力 | generator,period,available_mw | 使用 G 行号；每台机组完整 16 时段，出力非负。 |

模板可在目标配置面板下载。数据缺失、编号错误或不完整时不能确认该目标。没有成本数据时可使用出力调整或网损目标。

## 5. 无解诊断

示例：

```text
第1时段，机组G237有功出力设为2000MW。
```

校验将定位该目标与机组上限的冲突。其他预检包括上下限倒置、停机与非零目标冲突、固定出力超限、检修形成孤岛等。求解器 IIS 入口为独立接口，连接支持该功能的求解后端后使用。

## 6. 地图、网架与坐标

“地图与网架”并列展示大理行政区地图和电气连接布局。可按 B / L 编号定位，筛选网状部分，按时段查看开断和越限。

在“数据与接口 → 设备地理定位”上传 CSV：

```csv
bus_id,longitude,latitude
```

使用 WGS84 经纬度和真实 B 编号，不接受未知对象、重复编号或非法坐标。上传后，已有坐标的母线及两端均有坐标的线路显示到地理地图。没有坐标的对象仍在电气网架中显示。

## 7. 历史计算

历史页载入 E2 滚动工况，提供 16 时段目标、网损、电压、出力、开断矩阵和事故结果。该方案来自 MATLAB / MATPOWER MIPS，独立于工作台中新建的指令任务。

当前 E2 每时段的不开断基准为 103/107，选中方案为 102/106，均保留 4 个失败事故。开断 L151 后事故集合减少一个元素。工况设置页可查看方法与数据范围，完整记录可下载为 JSON。

## 8. 测点、聚合与测评

课题 2 静态表和动态表可分别上传 CSV / XLSX。页面显示原始列、记录与待匹配字段，提供字段模板。测点到节点的实际转换、设备操作回写仍需映射规则。

研究模块提供按电压等级 / 区域的节点分组和时间分组，计算负荷、机组等统计并导出 JSON。电气等值、知识增强分解、多智能体、CMDP 和强化学习显示对应开发状态。

测评模式接受 1–200 条 JSON / CSV 指令。含参考层级或规格的用例参与统计；只有指令、没有答案的用例显示“未标注”，不计入准确率。运行后可查看逐例结果并导出 Markdown / CSV。

## 9. 常见问题

**无法启动：** 用 Python 3.11 执行 `python -m pip install -r requirements.txt`，再运行启动脚本。端口已被同一平台占用时直接打开页面，不要重复启动。

**模型选项不可选：** 对应服务尚未配置。演示规则引擎不需要外部服务。

**确认或求解按钮不可用：** 补齐追问、推断幅度和必填数据；确认当前版本；消除校验错误后继续。

**结果中没有调整后曲线：** 当前是演示占位或外部结果没有提供该数据。载入完整结果后再比较。

**旧页面仍在显示：** 刷新浏览器；前端源码修改后需在 `frontend` 执行 `npm run build`。
